# Улучшения Allure отчетов

## Обзор изменений

Проведен рефакторинг для улучшения отображения тестов в Allure отчетах и добавлена интеграция с Graylog.

## Новые возможности

### 1. Allure Helpers (`utils/allure_helpers.py`)

Создан класс `AllureHelper` с методами для:
- Прикрепления информации об окружении
- Прикрепления информации о страницах (URL, заголовки, viewport)
- Прикрепления HTTP запросов/ответов
- Детального логирования ошибок с трассировкой
- Прикрепления тестовых данных с автоматическим маскированием паролей
- Прикрепления логов консоли браузера
- Прикрепления сетевых запросов
- Установки параметров тестов
- Установки ссылок (issue, tms)
- Прикрепления метрик производительности

### 2. Интеграция с Graylog (`utils/graylog_integration.py`)

Создан класс `GraylogIntegration` для отправки логов в Graylog:
- События начала/завершения тестов
- События начала/завершения сессий
- Детали ошибок
- Статистика выполнения

### 3. Улучшенные тесты авторизации

Тесты авторизации (`tests/test_auth.py`) теперь включают:
- Детальные описания с шагами и ожидаемыми результатами
- Правильные уровни severity (CRITICAL, HIGH, NORMAL)
- Автоматическое прикрепление информации об окружении
- Прикрепление тестовых данных (с маскированием паролей)
- Прикрепление информации о страницах на каждом шаге
- Прикрепление метрик производительности
- Улучшенная структура шагов

### 4. Улучшенные pytest хуки (`tests/conftest.py`)

Добавлены хуки для:
- Автоматического логирования начала тестов в Graylog
- Автоматического логирования завершения тестов
- Автоматического прикрепления деталей ошибок в Allure
- Автоматического прикрепления информации об окружении
- Сбора и отправки статистики сессии в Graylog

## Использование

### В тестах

```python
from utils.allure_helpers import AllureHelper

def test_example(page, config):
    # Прикрепление информации об окружении
    AllureHelper.attach_environment_info(config)
    
    # Прикрепление тестовых данных
    AllureHelper.attach_test_data({
        "email": "test@example.com",
        "password": "***MASKED***"
    })
    
    # Прикрепление информации о странице
    AllureHelper.attach_page_info(page, "Страница после действия")
    
    # Прикрепление метрик
    AllureHelper.attach_performance_metrics({
        "Время загрузки": "1.5s",
        "Статус": "Успешно"
    })
```

### Настройка Graylog

Добавьте в `.env`:
```env
GRAYLOG_ENABLED=true
GRAYLOG_URL=graylog.example.com
GRAYLOG_PORT=12201
```
