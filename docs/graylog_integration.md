# Интеграция с Graylog

Проект поддерживает интеграцию с Graylog для централизованного логирования результатов тестирования.

## Настройка

### Переменные окружения

Добавьте следующие переменные в ваш `.env` файл:

```env
# Включение интеграции с Graylog
GRAYLOG_ENABLED=true

# URL сервера Graylog
GRAYLOG_URL=graylog.example.com

# Порт Graylog (по умолчанию 12201 для GELF)
GRAYLOG_PORT=12201
```

### Использование

Интеграция автоматически активируется при запуске тестов, если:
1. `GRAYLOG_ENABLED=true` (или `1`, `yes`)
2. Указан `GRAYLOG_URL`

### Отправляемые события

Интеграция отправляет следующие типы событий:

1. **Начало сессии тестирования** (`session_start`)
   - Общее количество тестов
   - Окружение (dev, sm, ask-yug)

2. **Начало теста** (`test_start`)
   - Имя теста
   - Класс теста
   - Файл теста
   - Окружение

3. **Завершение теста** (`test_finish`)
   - Имя теста
   - Статус (passed, failed, skipped, broken)
   - Длительность выполнения
   - Сообщение об ошибке (если есть)

4. **Ошибки** (`error`)
   - Тип ошибки
   - Сообщение об ошибке
   - Трассировка стека
   - Имя теста

5. **Завершение сессии** (`session_finish`)
   - Общее количество тестов
   - Количество успешных тестов
   - Количество проваленных тестов
   - Количество пропущенных тестов
   - Длительность сессии
   - Процент успешности

### Формат сообщений

Сообщения отправляются в формате GELF (Graylog Extended Log Format) через UDP или TCP.

### Примеры запросов в Graylog

Для поиска событий тестирования используйте следующие запросы:

```
# Все события тестирования
_event_type:test_*

# Проваленные тесты
_test_status:failed

# Тесты конкретного окружения
_environment:dev

# Ошибки за последний час
_event_type:error AND timestamp:[now-1h TO now]
```

### Отключение интеграции

Для отключения интеграции установите:

```env
GRAYLOG_ENABLED=false
```

Или просто не указывайте `GRAYLOG_URL`.

## Дополнительная информация

Интеграция использует библиотеку `requests` для отправки сообщений. Все сообщения отправляются асинхронно и не блокируют выполнение тестов.

При недоступности сервера Graylog, ошибки логируются, но не прерывают выполнение тестов.
